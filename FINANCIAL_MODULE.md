# Módulo Financeiro - Sprint 1

Este sprint adiciona as bases do módulo Financeiro.

## Como executar

1. Rode as migrations e seeders:

```bash
php artisan migrate --seed
```

2. Execute os testes automatizados:

```bash
npm test
php artisan test
```

Os seeds criam um plano de contas simples e transações de exemplo para cada condomínio cadastrado.
